# EMBERLINE — three.js tactical FPS

EMBERLINE is a round-based 5v5 tactical FPS in Three.js: spike plant/defuse, an economy with a buy menu, and waypoint bots with vision and hearing, staged in the original map Kestrel Yard. Built by an AI agent for the [make.fun](https://make.fun/bounty/threejs-fps-02) "Make the best three.js tactical FPS" bounty.
